AIM

To implement and visualize CPU scheduling algorithms FCFS, SJF, Round Robin and Multi-Level Feedback Queue, and calculate completion, turnaround and waiting times.

  4. Record CT, TAT, WT and the average values.
  5. Compare the results of different algorithms using the same input.
Pseudocode
FCFS:
Sort processes by arrival time, then insertion order.
For each process:
  time = max(time, arrival)
  run process for full burst
  completion = time

SJF (non-preemptive):
While processes remain:
  choose arrived unfinished process with shortest burst
  if none has arrived: jump to next arrival
  run chosen process to completion

Round Robin:
Keep a FIFO ready queue.
Add newly arrived processes at each scheduling point.
Run head for min(quantum, remaining burst).
Append new arrivals, then requeue unfinished head.

MLFQ (3 levels, simplified):
New processes join highest priority Q0.
Q0 quantum = q; Q1 quantum = 2q; Q2 = FCFS.
Always choose the highest nonempty queue.
Demote unfinished processes after using their time slice.
A newly arrived higher-priority process preempts Q1/Q2.
No aging or periodic priority boost is applied.
Reference C code — FCFS
#include <stdio.h>
int main() {
    int n, at[50], bt[50], ct[50], tat[50], wt[50], i, j, t=0;
    printf("Enter number of processes: ");
    scanf("%d", &n);
    for(i=0;i<n;i++) {
        printf("AT and BT for P%d: ",i+1);
        scanf("%d%d", &at[i], &bt[i]);
    }
    // Input should be supplied in nondecreasing arrival order.
    for(i=0;i<n;i++) {
        if(t<at[i]) t=at[i];
        t+=bt[i]; ct[i]=t;
        tat[i]=ct[i]-at[i]; wt[i]=tat[i]-bt[i];
    }
    printf("P AT BT CT TAT WT\n");
    for(i=0;i<n;i++)
        printf("P%d %d %d %d %d %d\n",i+1,at[i],bt[i],ct[i],tat[i],wt[i]);
    return 0;
}

FAQs / viva questions

What is CPU scheduling? Choosing which ready process uses the CPU next.

What is preemption? Interrupting a running process so another can execute.

Is FCFS preemptive? No.

Which SJF variant is used? Non-preemptive SJF.

Why does RR need a quantum? To limit how long each process runs before other ready processes get a turn.

What is MLFQ? Multiple priority queues with different scheduling rules; unfinished processes can move to lower-priority queues.

What is starvation? A process waits indefinitely because other processes keep being prioritized.

What is turnaround time? Completion time minus arrival time.
